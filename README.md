# mysh

Учебный проект: командный интерпретатор (shell) на языке C. Эталон
поведения — bash.

## Состояние

Готовы две первые фазы конвейера `строка → токены → дерево команд`
и начало третьей (исполнитель):

- **лексер** — разбиение строки на слова и операторы, кавычки, экранирование,
  комментарии;
- **парсер** — разбор всей грамматики из ТЗ (простые команды,
  перенаправления, конвейеры, `&&` / `||`, списки, подоболочки) в дерево
  команд.

Исполнитель реализован частично: можно запустить одну простую команду
(внешнюю программу) с перенаправлениями `<`, `>`, `>>`. Конвейеры, списки,
подоболочки, встроенные команды и управление заданиями пока не реализованы
(выводится `not implemented yet`). Отладочные режимы показывают результат
лексера и парсера. Подробности — в
[report.md](report.md).

## Сборка

Нужны `gcc` (или `clang`), `make`, Linux (проверялось в WSL).

```bash
make          # релизная сборка -> ./mysh
make debug    # со sanitizers (address, undefined) -> ./mysh-debug
make test     # тесты лексера и парсера
make clean    # удалить собранные файлы
```

## Запуск

```bash
./mysh --dump-tokens -c 'echo "a  b" | wc -l'    # токены одной строки
./mysh --dump-ast    -c '(echo a; echo b) | wc'  # дерево команд одной строки
./mysh --dump-ast                                 # команды из stdin
```

Пример:

```
$ ./mysh --dump-ast -c 'echo a | wc && ls'
AND_OR
  PIPELINE
    SIMPLE argv=[echo a]
    SIMPLE argv=[wc]
  &&
  SIMPLE argv=[ls]
```

Коды возврата: `0` — успех, `1` — нехватка памяти или неверные аргументы,
`2` — синтаксическая ошибка. Если ввод идёт из терминала, показывается
приглашение `mysh> `, а недописанная команда (незакрытая кавычка, `\` в конце
строки) дочитывается со следующей строки.

## Тесты

```bash
make test                              # на обычной сборке
bash tests/run_tests.sh ./mysh-debug   # на сборке с sanitizers
```

Файлы тестов: `tests/syntax.txt` (принято / отвергнуто, с проверкой по
`bash -n`), `tests/golden.txt` (точный вывод `--dump-tokens` и `--dump-ast`),
`tests/run_tests.sh` (запуск).

## Структура

```
src/
├── lexer.h, lexer.c           лексер: строка → token_list
├── ast.h,   ast.c             дерево команд: типы, память, печать
├── parser.h, parser.c         парсер: token_list → дерево (рекурсивный спуск)
├── executor.h, executor.c     исполнитель (пока одиночная простая команда)
├── redirect.h, redirect.c     перенаправления < > >> (open, dup2)
├── mysh_getline.h, .c         чтение строки из потока
└── main.c                     временная точка входа (--dump-tokens, --dump-ast)
tests/                         тесты
Makefile
report.md                      отчёт о работе
```
